An enterprise-style AI-powered data analytics platform built using **Streamlit**, **Scikit-learn**, **Plotly**, and **OpenAI**.

This platform enables users to:

- Upload datasets
- Clean and preprocess data
- Visualize data interactively
- Automatically train multiple ML models
- Detect Classification/Regression problems
- Compare algorithms
- Select the best model
- Generate predictions from user input
- Generate AI-powered business insights

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/ai-autonomous-analyst.git
```

---

## Navigate to Project

```bash
cd ai-autonomous-analyst
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# 🔑 OpenAI API Setup

Create:

```text
.env
```

Add:

```env
OPENAI_API_KEY=your_openai_api_key
```

---

# ▶️ Run Application

```bash
python -m streamlit run app.py
```

---

# ☁️ Streamlit Cloud Deployment

## Add Secret

In Streamlit Cloud:

```toml
OPENAI_API_KEY = "your_openai_api_key"
```
